# Local results and QA

`exploration/` contains descriptive dataset tables and figures; `qa/` contains human-facing curation diagnostics. Other local presentation outputs may also be stored here. The whole generated tree is excluded from Git except for this README.

Recreate results with [`scripts/exploration/`](../scripts/exploration/README.md) and [`scripts/diagnostics/`](../scripts/diagnostics/README.md). A reviewed figure intended for the repository README is copied to [`assets/generated/`](../assets/README.md).
