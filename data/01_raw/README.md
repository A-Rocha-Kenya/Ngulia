# Raw source data

This folder holds the original ring-event workbooks, daily-count sources, weather archives, and external source collections. Keep source files unchanged. Record corrections in [`config/`](../../config/README.md) and rebuild the derived tables with [`scripts/`](../../scripts/README.md).

The source collections are local and are not distributed through Git. Source conventions and provenance are described in [the dataset guide](../../docs/dataset.md).
