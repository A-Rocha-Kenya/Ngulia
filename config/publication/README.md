# Publication metadata

`dataset_metadata.yml` is the shared source for the GitHub README and citation, Zenodo worksheet and README, and GBIF EML and archive. Update it when a verified DOI, dataset version, rights statement, or publication link changes; then rerun [`scripts/exports/`](../../scripts/exports/README.md).

Current record status and publication order are in [the publication guide](../../docs/publication.md). A value in this file is not proof that a public record exists.
