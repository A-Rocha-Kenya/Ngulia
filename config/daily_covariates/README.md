# Daily covariate evidence

`operations_history.csv` is the source- and page-linked register for historical lights, nets, playback, vegetation, staffing, and interruptions. Only reviewed date-specific values are applied to `daily_coverage.csv`; broad historical periods remain contextual evidence.

Read [the full evidence rules and historical interpretation](../../docs/daily_covariates.md) before editing this register. The daily-table build is under [`scripts/intermediate/`](../../scripts/intermediate/README.md) and [`scripts/curated/`](../../scripts/curated/README.md).
