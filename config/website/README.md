# Website taxonomy mapping

`ngulia_taxonomy_crosswalk.csv` maps dataset taxa to the names and identifiers used in website exports. The export builder under [`scripts/exports/`](../../scripts/exports/README.md) reads this file; the public website lives in the separate `ngulia-website` repository.

Review crosswalk changes against the curated species reference before regenerating website data. See [the dataset guide](../../docs/dataset.md) for taxonomy decisions.
